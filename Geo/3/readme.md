В условиях жёсткой конкуренции выбор правильного места для размещения бизнеса может стать решающим фактором его успеха. Оптимальное расположение позволяет минимизировать издержки, улучшить клиентский опыт и повысить доходность. С учётом географических масштабов страны и большого количества параметров, выбор на основе экспертного решения — процесс, слишком затратный с точки зрения необходимых ресурсов. Геоаналитика — это неотъемлемая часть бизнес-планирования, и ваша модель может стать ключевым инструментом для оптимизации этого процесса.

В рамках данного задания вам предлагается разработать модель машинного обучения, которая на основе географических данных и бизнес-показателей сможет предсказать, какие локации окажутся наиболее успешными для открытия новых точек различных типов бизнеса. Для этого ваша модель должна предсказывать сумму транзакций для той или иной локации.
